## About

This project takes a deep dive into a single definition in Ring Theory — **irreducible elements** — and explores it thoroughly through examples, proofs, and connections to broader algebraic structures. Inspired by a lecture-style approach where a single definition is unpacked fully before moving forward.

> *"Most students blindly read a definition without asking potential questions."*  
> This project aims to fix that.

## Key Results Covered

- **Theorem 1**: In an Integral Domain, every prime element is irreducible
- **Theorem 2**: In a UFD, prime ⟺ irreducible
- **Theorem 3 & 4**: Characterization of irreducibles in ℝ[x]
- **Theorem 5**: Rational Root Theorem (with proof)
- **Theorem 6**: Eisenstein's Criterion (with proof)
- **Theorem 7**: Reduction Modulo p criterion
- **Theorem 8**: In a UFD, p irreducible ⟺ ⟨p⟩ is a prime ideal
- **Theorem 9**: In a PID, p irreducible ⟺ ⟨p⟩ is a maximal ideal

---

## Notable Highlights

- Counterexample showing irreducible ⇏ prime: **2 in ℤ[√5i]**
- Swinnerton-Dyer polynomial **x⁴ − 10x² + 1** — irreducible over ℚ but resists all standard tests
- Hierarchy: Euclidean Domain ⊂ PID ⊂ UFD ⊂ Integral Domain
